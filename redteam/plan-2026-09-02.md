**Goal:** try to get around Sentinel's detection with benign test samples.
**Scope constraint (operator):** every sample lives inside `tests/samples/` in
this repo. Nothing is planted outside it (no real Cursor install path, no
registry writes, no real `%TEMP%` drops). No malicious payloads — every

**Method:** copy benign Windows binaries to mimic paths inside

script names / trailing args) so the 5-minute dedup can't swallow a result;
each "expected quiet" test gets a **control** (same parent, one deviation)
that must fire — if the control fires and the exact shape stays silent, the
silence is attributed to the filter, not to lost telemetry.

**Expected desktop effect:** up to ~6 CRITICAL toast popups. That is the
test working, not a problem.

## The weak point being tested (found by reading `rules.d/exec.yml`)

`filter_cursor_agent` (silences EXEC-001/PERSIST-001 for Cursor's own
bridge) anchors BOTH its patterns with end-of-string `$` and **no start
anchor**:

```yaml
ParentImage|re: '(?i)\\appdata\\local\\programs\\cursor\\(?:_\\)?cursor\.exe$'
CommandLine|re: '(?i)^\s*"?[^\s"]*powershell\.exe"?\s+-ExecutionPolicy Bypass -NonInteractive -File "?[^\s"]*\\AppData\\Local\\Temp\\ps-script-<GUID>.ps1"?\s*$'
```

Suffix-only means **any** tree *ending* in `...\appdata\local\programs\cursor\cursor.exe`
qualifies as trusted parent — not just the real install path. E.g.
`D:\stuff\appdata\local\programs\cursor\cursor.exe` or a tree inside this
repo. The documented residual says "planted AT the real install path";
if suffix trust holds, the residual is wider than documented.

### FINDING (new, bounded): suffix-only trust in filter_cursor_agent

Both anchors in EXEC-001/PERSIST-001's `filter_cursor_agent` are end-of-
string anchored with NO start anchor. Confirmed live (T1, T7): a benign
binary at `…\tests\samples\lab\appdata\local\programs\cursor\cursor.exe`
running the exact bridge shape, with the script under
`…\lab\appdata\local\temp\ps-script-<guid>.ps1`, is **quiet for both
EXEC-001 and PERSIST-001**. The documented residual said "planted AT the
real install path"; in reality ANY tree ending in
`\appdata\local\programs\cursor\cursor.exe` qualifies — repo subfolder,
USB stick, download dir, archive mount.

**Impact is bounded (verified live):**
- file_capture vaulted both quiet scripts (contains-based pattern) with
  full manifests — content is inspectable despite the silence
- NET-005 fired CRITICAL on a repo-path connector (T6) — the
  loopback-C2 incident pattern stays visible
- every other rule (CRED/INJECT/EVADE/PERSIST-003/004, EXEC-002/003
  armed shapes) unaffected — only the two bridge rules are quieted

**Possible fix (operator decision, NOT auto-applied):** anchor the parent
to a real profile prefix, e.g.
`(?i)^[a-z]:\\users\\[^\\]+\\appdata\\local\\programs\\cursor\\(?:_\\)?cursor\.exe$`
(and the same prefix idea for the script-path side). Costs nothing today —
the current quiet set is a superset of the fixed one — and removes the
"trusted shape on a removable drive" case. Junction residual (handoff §4)
is unchanged either way.
